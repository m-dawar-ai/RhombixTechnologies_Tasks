# 🧠 Memory Puzzle Game

A fun and interactive web-based memory puzzle game developed using **Python, Flask, HTML, CSS, and JavaScript**.

The goal is simple: match all the pairs of cards before the timer reaches zero.

## 🎯 Features

- 🃏 4×4 memory card grid
- ⏱️ Countdown timer
- 🎯 Moves counter
- ✅ Matches counter
- 🔄 New Game button
- 🏆 Completion detection
- ⏰ Time-limit challenge
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
